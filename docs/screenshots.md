# Screenshot Guidance

Store README screenshots in `docs/assets`.

Use exactly these filenames for the README placeholders:

- `docs/assets/clinvision-result.png`: main application view showing upload, completed inference result, report text, and Grad-CAM overlay.
- `docs/assets/clinvision-dashboard.png`: either the Grafana dashboard or the application inference history view.

Keep screenshots lightweight and avoid committing generated uploads, heatmaps, database files, `.env`, `.next`, or `node_modules`.
